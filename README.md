# المِحَك · Mihak — The Touchstone

منصة تختبر طرق التداول ضد بعض بالأرقام، وتكشف أي وحدة تربح فعلاً.

مسابقة تداول **ورقي** (بدون فلوس حقيقية) على أسعار Binance الحية، بين طريقتين وحَكَمين:

| المتسابق | شلون يقرر |
|---|---|
| Qwen · لحاله | كل 15 دقيقة: Grok يجيب الأخبار، وQwen يدوّر أقوى فرصة ويدخل فوراً |
| Qwen · اجتماع (مدير موديل) | نفس فرص Qwen، وقبل الدخول اجتماع خبراء (اتجاه، أخبار، مخاطر) ومدير موديل يقرر |
| Qwen · اجتماع (مدير كود) | نفس الفرص ونفس الأصوات، والقرار بقاعدة ثابتة: خبيرين يوافقون ومتوسط ثقتهم 60+ |
| DeepSeek · (نفس الفروع الثلاثة) | نفس الفكرة، لكن DeepSeek هو الكشّاف |
| الماضي · استراتيجية | استراتيجية مختبرة في TradingView ترسل إشارات شراء/بيع |
| العشوائي (حَكَم) | يدخل بالقرعة بنفس الهدف والوقف |
| اشترِ واحتفظ BTC (حَكَم) | يشتري بتكوين أول يوم ويقعد |

**القاعدة:** الفائز لازم يغلب الحَكَمين الاثنين.

**قياس الاجتماع:** كل فرصة يلقاها الكشّاف تنتابع لين نهايتها حتى لو الاجتماع رفضها، فنعرف صدق كل خبير وكل مدير، وهل الصفقات المرفوضة كانت بتخسر فعلاً.

كل المتسابقين: سبوت فقط (بدون رافعة ولا بيع على المكشوف)، عملات من قائمة `halal-coins.json`، ورسوم 0.1% لكل جهة مع انزلاق 0.05%.

## 1. التجربة على جهازك (بدون أي مفاتيح)

1. نزّل Node.js نسخة 20.6 أو أحدث من nodejs.org
2. افتح الطرفية داخل مجلد المشروع وشغّل:

```bash
npm install
npm run demo
```

3. افتح `http://localhost:3000`

وضع التجربة يستخدم أسعار وقرارات وهمية، فقط عشان تشوف اللوحة وتتأكد إن كل شي يشتغل.

## 2. التشغيل الحقيقي (تداول ورقي على أسعار حية)

انسخ `.env.example` باسم `.env` وعبّي:

| المتغير | من وين |
|---|---|
| `DASHBOARD_PASSWORD` | أي كلمة سر تختارها للوحة |
| `XAI_API_KEY` | console.x.ai (أخبار Grok) |
| `OPENROUTER_API_KEY` | openrouter.ai (Qwen و DeepSeek) |
| `WEBHOOK_SECRET` | أي نص طويل عشوائي (لإشارات TradingView) |
| `MCP_SECRET` | أي نص طويل عشوائي (لموصّل Claude، اختياري) |

ثم:

```bash
npm run start:env
```

## 3. على سيرفر Railway (للمسابقة الرسمية)

1. railway.app ← New Project ← Deploy from GitHub repo ← اختر هذا المستودع
2. Variables: أضف المتغيرات اللي فوق، وأضف `DB_FILE=/data/db.json`
3. Settings ← Volumes: أضف Volume على المسار `/data` (حتى ما تضيع النتائج إذا السيرفر أعاد التشغيل)
4. Settings ← Networking ← Generate Domain: هذا رابط لوحتك

## 4. ربط "الماضي" مع TradingView

في تنبيه الاستراتيجية على TradingView:

- **Webhook URL:** `https://رابطك/api/webhook/strategy`
- **Message:**

```json
{"secret":"WEBHOOK_SECRET","action":"{{strategy.order.action}}","symbol":"{{ticker}}","reason":"{{strategy.order.comment}}"}
```

اختياري: `"stopLossPercent": 3` و `"takeProfitPercent": 6` داخل الرسالة. إذا ما انرسل وقف، ينطبق الوقف الافتراضي من القوانين.

## 5. المسابقة الرسمية

- قبل البداية: **وضع الإحماء**. القوانين مفتوحة والنتائج للتجربة.
- لما تجهز (المفاتيح + استراتيجية "الماضي")، من الإعدادات: **ابدأ المسابقة الرسمية**. الكل يتصفّر بنفس اللحظة، والقوانين تنقفل.
- المدة المقترحة: 8 أسابيع.
- التقييم: العائد بعد الرسوم، أكبر تراجع، العائد ÷ التراجع، وتكلفة الذكاء الاصطناعي.

## 6. موصّل Claude (MCP)

Claude يقدر يقرا المسابقة ويتحكم فيها من claude.ai.

1. حط `MCP_SECRET` في متغيرات Railway (نص طويل عشوائي).
2. claude.ai ← Settings ← Connectors ← Add custom connector، والرابط:

```
https://رابطك/mcp/MCP_SECRET
```

- **قراءة:** نظرة عامة، متسابق، صفقات، فرص، اجتماعات، قوانين، أخبار.
- **كتابة:** تعديل القوانين، تشغيل متسابق موقوف، تحديث الأخبار، إغلاق صفقة.
- **بدء/تصفير المسابقة:** يحتاج `confirm` بالكلمة `START` أو `RESET`.
- السر في الرابط هو الحماية الوحيدة؛ لا تشارك الرابط. لو انكشف، غيّر `MCP_SECRET`.

## اللي تغيّر عن النسخة القديمة

- شلنا مفتاح Gemini اللي كان مكتوب داخل الكود. كل المفاتيح الحين في `.env`
- السيرفر القديم كان يعرض كل ملفات المجلد للمتصفح (ومنها المفاتيح والبيانات). الحين يعرض اللوحة بس، وعليها كلمة سر.
- الرسوم والانزلاق صارت تنحسب في كل صفقة.
- نسبة الفوز صارت عدد الصفقات الرابحة ÷ عدد الصفقات المغلقة (القديمة كانت تحسبها من المبالغ، فتطلع أعلى من الحقيقة).
- وقف الخسارة يتنفذ على السعر الفعلي إذا السعر قفز تحت الوقف، مو على سعر الوقف بالضبط.
- الإيقاف بعد الخسائر المتتالية صار يرجع تلقائياً بعد مدة، حتى ما يحتاج تدخل يدوي بالنص.
